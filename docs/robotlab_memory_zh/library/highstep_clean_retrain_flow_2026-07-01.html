为什么不复刻全部历史

应保留的经验

1. Bodyflat 预训练作为基础。

2. Highstep 改成阶段任务，而不是无约束叠 dense reward。

3. 第一后腿搭台、post-lead 支撑、第二后腿清台必须作为动作链判断。

4. hard terrain 可以短 refine，但不能默认长训到底。

不应复刻的冗余

1. 06-23/06-24/06-25 多个旧 reward mix 分支不应机械全复现。

2. 06-28 的前腿护栏过强分支、support_pose_scale=0 分支不应作为主线。

3. 07-01 从 140400 长训到 148700 的后半段已经显示支撑能力退化。
